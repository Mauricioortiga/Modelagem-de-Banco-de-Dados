**Objetivos de Aprendizagem:**

**Modelagem de Dados:** Construir a base teórica e prática essencial para o desenvolvimento de sistemas.

**Dados vs. Informação:** Diferenciar conceitos fundamentais no fluxo de processamento de dados.

**Ética e Legislação:** Compreender a responsabilidade ética e as normas legais no tratamento de dados.

**Estruturas de Dados:** Conhecer os diferentes tipos de estruturas utilizadas no cenário tecnológico atual.

**Relevância Profissional e de Mercado:**

**Tomada de Decisão:** Capacitar o profissional de tecnologia a estruturar, proteger e gerenciar dados de forma estratégica.

**Qualidade de Software:** Garantir a criação de sistemas mais robustos, seguros e eficientes.

**Alinhamento do Mercado:** Atender às exigências crescentes de um ecossistema digital em constante evolução.
