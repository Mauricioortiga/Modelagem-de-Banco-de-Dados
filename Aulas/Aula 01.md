Modelo conceitual (MER) - Modelo / Entidade / Relacionamento

**-> Entidades: Conjunto de objetos ou conceitos que possuem as mesmas características em comum. (A ENTIDADE SERÁ SEMPRE UM SUBSTANTIVO)**

Exemplo: Cliente, produto.

-> Atributos: Características ou propriedades das entidades.

Exemplo: Nome e CPF do cliente.

-> Relacionamentos: Como as entidades se ligam entre si.

O relacionamento no BD é um LOSANGO!

O que se aplica dentro é um VERBO! O VERBO não é no infinitivo, ele é conjugado. 

Exemplo: Ele FAZ, ele APRENDE, ele LECIONA.

Um cliente faz uma compra.

-> Cardinalidade: A quantidade de objetos que interagem entre uma entidade que se liga a outra.

Exemplo: 1 para 1, 1 para n(muitos) ou n(muitos) para n(muitos).

O MER é o conjunto de conceitos teóricos e a estrutura abstrata dos dados.

Toda entidade é um substantivo - É um conjunto de objetos que possuem as mesmas características.

 Questão de prova:

Qual é a cardinalidade entre aluno e disciplina?

N para N.
